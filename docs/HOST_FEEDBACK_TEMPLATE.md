# HOST_FEEDBACK_TEMPLATE

本文档提供宿主项目对 `main-ui` 或 `viewport-2d-kit` 的标准反馈模板。

建议每次接入或升级后，至少输出一份正式反馈文档，而不是只在聊天中留下零散结论。

## 模板

```md
# report-<宿主项目反馈包>-日期-UID

## 1. 基本信息

- 宿主项目：
- 关联底层包：`main-ui` / `viewport-2d-kit`
- 反馈主题：
- 反馈类型：API / 文档 / 示例 / 兼容 / 体验

## 1.1 前置规范确认

- 是否已阅读接入前必读规范：是 / 否
- 已阅读文档：
- 若未完整阅读，说明缺失项：

## 2. 当前行为

描述当前实际发生的行为。

## 3. 期望行为

描述宿主期望看到的行为。

## 4. 复现步骤

1. 
2. 
3. 

## 5. 影响范围

说明影响的是单个 editor、单个 workspace、整个宿主工作台，还是构建/运行链路。

## 6. 已有 workaround

- 是否存在 workaround：是 / 否
- 若存在，说明临时处理方式：

## 7. 证据

- 相关日志：
- 相关截图或录屏：
- 相关文件或代码位置：

## 8. 建议动作

- 建议修 API / 补文档 / 补示例 / 补迁移说明 / 明确拒绝并解释边界
```

## 最小要求

一份有效反馈至少必须回答：

1. 现在发生了什么。
2. 期望发生什么。
3. 如何复现。
4. 影响范围多大。
5. 有没有 workaround。
6. 问题发生前，宿主是否已阅读并遵守前置规范。
