# manual-viewport-3d-kit-用户手册-20260311-001

## 1. 文档目的

本文档面向工具包使用者，说明如何在 Vue3 项目中接入 `viewport-3d-kit`，并正确使用主视口、变换工具和小地图。

## 2. 功能概览

当前工具包提供以下能力：

- 主视口组件 `Viewport3D`
- 菜单子组件 `Viewport3DMenu`（Vue）
- 小地图子组件 `Viewport3DMiniMap`（Vue）
- 小地图组件 `MiniMap3D`（React 兼容层）
- 右键菜单与工具栏 UI（可选）
- 运行模式 / 编辑模式（默认运行模式）
- 基础对象选择与高亮
- 变换模式切换：平移、旋转、缩放
- Blender 显示模式：Wireframe、Solid、Rendered
- Unreal 运行导航开关（运行模式默认开启）
- 中键修饰键方案开关（中键平移、Alt+中键缩放、Ctrl+中键旋转）
- 受控/非受控状态管理（小地图、选中对象、变换模式、对象变换、相机状态）
- 相机命令：视角放大、视角缩小、重置视角、聚焦选中对象

技术栈说明：

1. 主结构为 Core + Vue3。
2. Three.js 作为底层渲染引擎，本身不依赖 React。
3. React 入口作为兼容层保留，面向历史 React 工程或特定生态集成。
4. 输入控制细节统一下沉到 `core/viewport/input-controller`，Vue/React 交互行为保持一致。

## 3. 安装依赖

在宿主项目安装：

```bash
pnpm add viewport-3d-kit vue three
```

## 4. 快速接入

```vue
<script setup lang="ts">
import { computed, ref } from 'vue';
import { Viewport3D } from 'viewport-3d-kit/vue';
import { createDemoEntities } from 'viewport-3d-kit/core';

const entities = computed(() => createDemoEntities());
const miniMapEnabled = ref(false);
</script>

<template>
  <Viewport3D
    class-name="app-viewport"
    :entities="entities"
    :mini-map-enabled="miniMapEnabled"
    @update:mini-map-enabled="miniMapEnabled = $event"
  />
</template>
```

如果需要在 Vue 中独立复用菜单和小地图壳组件，可按需导入：

```ts
import { Viewport3DMenu, Viewport3DMiniMap } from 'viewport-3d-kit/vue';
```

## 5. 样式引入

如果你在当前仓库内联调（例如运行 `npm run dev`）并使用内置 UI（工具栏和右键菜单），可直接引入：

```ts
import 'viewport-3d-kit/src/styles/viewport.css';
import 'viewport-3d-kit/src/styles/radix-ui.css';
```

说明：

- `viewport.css` 定义了主视口容器、小地图定位和覆盖层布局。
- `radix-ui.css` 定义了工具栏和右键菜单样式。
- 发布到 npm 供外部项目消费时，建议在打包阶段显式导出样式入口，或将样式复制到宿主项目统一管理。
- 你也可以只保留结构类名并覆盖为业务样式。

## 6. 交互说明

在默认实现中：

- 左键单击对象：选中对象并高亮。
- 点击空白区域：清空选中。
- 工具栏按钮：切换运行/编辑模式。
- 工具栏按钮：切换平移、旋转、缩放模式。
- 工具栏按钮：切换 Wireframe/Solid/Rendered 显示模式。
- 工具栏按钮：支持视角放大、视角缩小、重置视角、聚焦选中。
- 工具栏复选框：切换 Unreal 运行导航。
- 工具栏复选框：切换中键修饰键方案。
- 拖拽 `TransformControls`：实时更新对象变换。
- 右键菜单：可切换模式、小地图开关、视角命令与取消选中。
- Vue 主实现与 React 兼容实现共用 Core 输入控制器，UE 导航、中键修饰键与快捷键语义一致。

快捷键说明：

- `G`：切换平移。
- `R`：切换旋转。
- `S`：切换缩放。
- `Z`：循环切换显示模式。

## 7. 关键属性

`Viewport3D` 常用属性：

- `entities?: ViewportEntity[]`：场景对象数组。
- `miniMapEnabled?: boolean`：受控小地图开关。
- `defaultMiniMapEnabled?: boolean`：非受控默认小地图状态。
- `miniMapMode?: 'top-down' | 'follow'`：小地图模式。
- `selectedEntityId?: string | null`：受控选中对象。
- `defaultSelectedEntityId?: string | null`：非受控默认选中对象。
- `transformMode?: 'translate' | 'rotate' | 'scale'`：受控变换模式。
- `defaultTransformMode?: 'translate' | 'rotate' | 'scale'`：非受控默认变换模式。
- `workMode?: 'runtime' | 'edit'`：受控工作模式。
- `defaultWorkMode?: 'runtime' | 'edit'`：非受控默认工作模式。
- `displayMode?: 'wireframe' | 'solid' | 'rendered'`：受控显示模式。
- `defaultDisplayMode?: 'wireframe' | 'solid' | 'rendered'`：非受控默认显示模式。
- `unrealRuntimeNavigation?: boolean`：受控 Unreal 运行导航开关。
- `defaultUnrealRuntimeNavigation?: boolean`：非受控 Unreal 导航默认值。
- `modifierMiddlePresetEnabled?: boolean`：受控中键修饰键方案开关。
- `defaultModifierMiddlePresetEnabled?: boolean`：非受控中键修饰键默认值。
- `entityTransforms?: EntityTransformMap`：受控对象变换字典。
- `defaultEntityTransforms?: EntityTransformMap`：非受控默认变换字典。
- `cameraState?: ViewportCameraState`：受控相机状态。
- `defaultCameraState?: ViewportCameraState`：非受控默认相机状态。
- `onCameraStateChange?: (state) => void`：相机状态变化回调。
- `onMiniMapEnabledChange`、`onSelectedEntityIdChange`、`onTransformModeChange`、`onWorkModeChange`、`onDisplayModeChange`、`onUnrealRuntimeNavigationChange`、`onModifierMiddlePresetEnabledChange`、`onEntityTransformsChange`：状态变化回调。

## 8. 受控与非受控使用建议

推荐在业务系统中优先使用受控模式：

- 便于将状态同步到上层状态管理。
- 便于做撤销/重做、权限控制、日志审计。

当你希望快速原型验证时，可采用非受控模式：

- 仅传入 `default*` 属性，内部自动维护状态。

## 9. 数据模型说明

`ViewportEntity` 基本结构：

```ts
interface ViewportEntity {
  id: string;
  name: string;
  position: [number, number, number];
  size: [number, number, number];
  kind?: 'box' | 'sphere' | 'cylinder';
  rotation?: [number, number, number];
  color: string;
}
```

`EntityTransformMap` 基本结构：

```ts
type EntityTransformMap = Record<
  string,
  {
    position: [number, number, number];
    rotation: [number, number, number];
    scale: [number, number, number];
  }
>;
```

## 10. 常见问题

### 10.1 小地图不显示

检查项：

- `miniMapEnabled` 是否为 `true`。
- 容器是否有足够高度（建议 `height >= 360px`）。
- 样式是否覆盖了 `.vk-minimap` 的定位或尺寸。

### 10.2 变换后外部状态未更新

检查项：

- 是否传入了 `entityTransforms` 但未实现 `onEntityTransformsChange`。
- 外部回调是否正确写回最新变换字典。

### 10.3 对象无法被选中

检查项：

- 对象 `id` 是否唯一。
- 是否有外层事件阻止了 Canvas 指针事件。
