# 示例集成

## 1. 当前示例结构

**推荐路径（pixi 内核）：**

1. pixi 渲染内核示例：`docs/examples/pixi-viewport-example.vue`（`PixiViewportCanvas` + world Graphics + 点击命中）

**历史兼容层示例（存量迁移期参考，新项目不要使用）：**

2. 地图编辑示例：`docs/examples/map-editor-example.tsx`（`Viewport2D`）
3. 笔记画布示例：`docs/examples/note-canvas-example.tsx`（`Viewport2D`）
4. 绘图工具示例：`docs/examples/drawing-tool-example.tsx`（`Viewport2D`）
5. 轻量模式示例：`docs/examples/lite-basic-example.tsx`（`ViewportLite`）
6. 模式宿主示例：`docs/examples/mode-host-example.tsx`（`ViewportModeHost`）
7. Vue 业务画布壳示例：`docs/examples/vue-business-canvas-shell-example.vue`（`ViewportBusinessCanvasShell`）

说明：新项目优先参考第 1 个示例；其余示例为历史兼容层演示。

## 2. pixi 内核最小示例（推荐）

```vue
<script setup lang="ts">
import { PixiViewportCanvas, type PixiViewport } from 'viewport-2d-kit/pixi';
import { Graphics } from 'pixi.js';

function onReady(vp: PixiViewport) {
  const g = new Graphics().circle(0, 0, 24).fill(0x2563eb);
  vp.world.addChild(g); // 世界坐标，相机由内核唯一管理
}
</script>

<template>
  <PixiViewportCanvas :view-box="{ x: -100, y: -100, width: 400, height: 400 }" @ready="onReady" />
</template>
```

## 3. main-ui 薄连接器示例

```ts
import { registerViewportMainUiEditor } from 'viewport-2d-kit/main-ui';

registerViewportMainUiEditor(runtime, {
  kind: 'viewport-foundation',
  title: 'Viewport foundation',
  rendererKey: 'viewport-foundation-editor',
  allowedWorkspaceIds: ['workspace-demo'],
});
```

## 4. 集成提示

1. `viewport-2d-kit/pixi` 为唯一渲染内核入口，`pixi.js` 是 peerDependency，业务侧需自行安装。
2. React 宿主使用 `viewport-2d-kit/react-pixi` 的 `PixiViewportReact`。
3. 旧示例可在迁移期继续运行，但新业务一律走 pixi 内核。
4. Vue 宿主若仍要使用自定义业务 renderer，优先复用 `ViewportBusinessCanvasShell`，不要在宿主重复维护 panel/stage/toolbar 样板。
